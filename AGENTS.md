## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Research data — expensive, do not overwrite

These files hold sweeps that take 20–40 minutes each over hundreds of live
sites. They are inputs to the outreach list and the market figures, not
disposable output.

| File | Holds | Regenerated by |
| :--- | :--- | :--- |
| `research/seal-census.json` | 489 sites: trust signals, blocks, providers | `node crawler/seal-census.mjs` |
| `research/affiliate-contacts.json` | 489 sites: affiliate addresses | `node crawler/affiliate-contacts.mjs` |
| `research/market-scan.json` | 489 sites: third-party hosts | `node crawler/market-scan.mjs` |
| `research/prospects-live.csv` | 491 verified-live casinos | `research/scripts/2-check-live.py` |

Each generator takes an optional limit as its first argument. A limited run
writes to `<name>.partial.json` and leaves the full file alone — that guard
exists because a 3-site smoke test once destroyed a 489-site sweep.

**Commit a sweep the moment it finishes.** Recovery is only possible from git.
If `git diff --stat` shows thousands of deleted lines in one of these files,
stop: count the records against `git show HEAD:<file>` before doing anything
else.
